# Leads Alicante — BorIA / Llevant Studio

Este directorio guarda los informes semanales de leads generados automáticamente
para Borja (BorIA / Llevant Studio): negocios de Alicante sin web propia o con
web claramente anticuada, candidatos a una demo de web hecha con IA.

La rotación semanal de sectores es:

1. Restaurantes y bares
2. Peluquerías y salones de belleza
3. Talleres mecánicos
4. Tiendas de barrio (ropa, alimentación, regalos)
5. Servicios locales (fontaneros, electricistas, gestorías, clínicas dentales)

El estado de la rotación se guarda en `rotation-state.json`. Cada informe
semanal se guarda como `YYYY-MM-DD-sector.md`.
